# ImageWorker の使い方

ImageWorker は、`png` と `jpg` のファイルが入ったフォルダーについて 2 つの問いに
答えます。

- **このアセットはスクリーンショットのどこに写っているか** — 主な用途です。
- **このフォルダーのどのファイルが重複か** — 副次的な用途です。

---

## 1. フォルダーを指定する

**画像**は探す対象のフォルダーです。**インデックスの場所**は ImageWorker が自分の
データ、つまりデータベース・プレビュー・記述子を置く場所です。

既定ではインデックスは画像フォルダー内の隠しフォルダー `.imageworker` に入ります。
画像が読み取り専用の場所やネットワーク共有にあるとき、他人のリポジトリに何も足したく
ないとき、あるいはインデックスを速いディスクに置きたいときは、**インデックスの場所**
を変更してください。**既定**で元に戻ります。

**インデックス作成**を押します。1 回目はすべてのファイルを読みますが、2 回目以降は
サイズか更新日時が変わったファイルだけを読み直すので、インデックスを最新に保つ費用は
わずかです。

> 合計約 400 MB の画像 4600 枚のインデックス作成は、ニューラル記述子を含めて
> おおよそ 3 分かかります。

---

## 2. スクリーンショットの中のアセットを見つける

**見本で検索**を開き、スクリーンショットを取り込みます。

- **Ctrl+V** でクリップボードから貼り付ける — どちらのタブからでも使えます。
- 画像ファイルをウィンドウにドロップする。
- または**参照**…を使う。

**探したい対象を枠で囲んでください。** これは見た目以上に効きます。画面全体では、
検索の労力の大半が背景に費やされます。4600 個のアセットのライブラリでは、枠で囲んだ
対象は画面全体の 5.6 秒に対して約 **2.6 秒**で済み、一致する点はおよそ**2 倍**
見つかります。どの点も背景ではなく対象の上に乗るからです。枠の外をクリックすると枠が
消え、再び画面全体を検索します。

**検索**を押します。最良の一致がスクリーンショット上に輪郭で示され、すべての結果が
順位付きで下に並びます。

### 結果の読み方

各結果には**スコア**と**インライア数**が表示されます。インライアとは、ひとつの整合
した配置で一致した点の数であり、これが根拠です。スコアはその一致がどれだけ*整合して
いた*かを評価し、数が少ないときは割り引かれます。

**結果は順位付きの一覧であって、はい・いいえの答えではありません。** 同じキャラクター
の別の絵も検証を通ります。絵の大部分は実際に一致するからです。正しいものは明確に上位に
来るので、唯一の勝者を探すのではなく順位を読んでください。

### 方式

- **画像内のオブジェクトを特定** — 上で述べたニューラル検索です。記述子を含む
  インデックスが必要で、項目が灰色の場合は下記を参照してください。
- **画像全体の類似度** — 画像を全体として比べる知覚ハッシュです。*同じ画像*の拡大縮小
  版や再エンコード版を見つけるのには向きますが、スクリーンショット内の小さなオブジェ
  クトを探すのには使えません。

**オブジェクトを特定**が無効なら、インデックスにまだ記述子がありません。コマンドライン
から一度だけ作成します。

```
imageworker index "<画像フォルダー>" --db "<インデックスフォルダー>\index.db" --features
imageworker vocab "<画像フォルダー>" --db "<インデックスフォルダー>\index.db"
```

## 3. 重複を見つける

**重複**を開き、**最大距離**を設定して**重複を検索**を押します。

- **完全一致**のグループはバイト単位で同一のファイルです。安心して扱えます。
- **近似**のグループは知覚ハッシュから見て似ています。**中身を確認してください。
  無条件に削除しないでください。** ハッシュは構図を表すため、表情違いの同じキャラク
  ターは、実用的なあらゆる距離でひとつのグループに入ります。

距離 0 は指紋が同一という意味で、4 は再エンコードや拡大縮小を許容します。8 を超えると
グループは確認用にしかなりません。

グループは無駄になっている容量の大きい順に並びます。グループ内では最も大きく解像度の
高いファイルが先頭に来ます。ふつうはそれが残すべきファイルです。

---

## 4. パスを取り出す

どの結果もフルパスを持っています。

- 下部のバーが現在の選択のパスを表示し、**コピー**は選択したパスをすべて 1 行ずつ
  コピーします。
- ファイル名の横の小さなコピーアイコンは、その 1 件だけをコピーします。
- 右クリックで、フルパス、フォルダーからの相対パス、またはファイルマネージャーでの
  表示を選べます。

---

## 5. テーマと言語

**表示 → テーマ**は、実行中にシステム・SF・Material・ブロッサムを切り替えます。
選択は記憶されます。

**表示 → 言語**も再起動なしでインターフェイスを切り替えます。一覧にはこのビルドが
持つすべての言語が並び、**システムの言語**は OS に従います。このマニュアルも翻訳
されており、マニュアルがまだ用意できていない言語では英語が表示されます。

---

## できないこと

- 知覚ハッシュが見つけるのは**同じ画像**であって、単に似た題材ではありません。
- ニューラル検索が見つけるのは画像に**実際に写っている**アセットです。説明文による
  検索ではありません。
- 特徴点がまったく得られないアセット — 単色の面や極小のアイコン — は位置を特定でき
  ません。一般的なアセットライブラリのおよそ 4% がこれに当たります。
