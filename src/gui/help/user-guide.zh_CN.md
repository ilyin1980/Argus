# Argus 使用说明

> *百眼巨人阿尔戈斯·潘诺普忒斯：他的眼睛总有一半睁着，另一半睡去，
> 因此没有任何东西能在他眼前溜过。*

Argus 针对一个存放 `png` 和 `jpg` 文件的目录回答两个问题：

- **这个素材出现在我的截图的什么位置？** —— 主要用途。
- **这个目录里哪些文件是重复的？** —— 次要用途。

---

## 1. 指定一个目录

**图片**是要搜索的目录。**索引位置**是 Argus 存放自身数据的地方：数据库、
预览图和描述子。

默认情况下索引会放进图片目录内一个名为 `.argus` 的隐藏目录。如果图片位于
只读目录或网络共享上、你不想往别人的仓库里添加任何东西、或者索引更适合放在更快
的磁盘上，就修改**索引位置**。**默认**会把它放回原处。

点击**建立索引**。第一遍会读取每个文件；之后只重新读取大小或修改时间发生变化的
文件，因此保持索引最新的代价很低。

> 为 4600 张、总计约 400 MB 的图片建立索引大约需要三分钟，包含神经网络描述子。

---

## 2. 在截图中找到素材

打开**按样例查找**，然后把截图放进来：

- 按 **Ctrl+V** 从剪贴板粘贴 —— 在两个标签页下都可用；
- 把图片文件拖到窗口上；
- 或者使用**浏览…**。

**用框圈出你要找的对象。** 这件事比看上去重要：在整幅画面上，搜索的大部分精力会
花在背景上。在 4600 个素材的库中，圈出对象大约耗时 **2.6 秒，而整幅画面为
5.6 秒**，而且找到的匹配点大约是**两倍**，因为每个匹配点都落在对象上而不是布景
上。在框外点击即可清除选框，重新搜索整幅画面。

点击**搜索**。最佳匹配会在截图上被勾勒出来，所有结果按排名显示在下方。

### 如何解读结果

每个结果显示一个**分数**和**内点数量**。内点是指那些在同一个一致位置上取得共识的
匹配点 —— 它们就是证据。分数衡量这些匹配有多**一致**，当数量很少时会被压低。

**结果是一个排序列表，而不是「是/否」的答案。** 同一角色的另一张画同样能通过校验，
因为画面的大部分确实吻合。正确的那一个会明显排在前面，所以请看排序，而不要指望
只有唯一的赢家。

### 方式

- **在图片中定位对象** —— 上面描述的神经网络搜索。需要包含描述子的索引；如果该
  选项是灰色的，请见下文。
- **整图相似度** —— 把图片作为整体比较的感知哈希。适合找到*同一张图片*被缩放或
  重新编码后的副本，无法在截图中找出其中的小对象。

如果**定位对象**不可用，说明索引还没有描述子。用命令行生成一次即可：

```
argus index "<图片目录>" --db "<索引目录>\index.db" --features
argus vocab "<图片目录>" --db "<索引目录>\index.db"
```

## 3. 查找重复图片

打开**重复图片**，设置**最大距离**，然后点击**查找重复**。

- **完全相同**的分组是逐字节一致的文件，可以放心处理。
- **相近**的分组在感知哈希看来相似。**请逐一查看，不要盲目删除。** 哈希描述的是
  构图，所以同一角色画出的多种表情，在任何可用的距离下都会落进同一组。

距离 0 表示指纹完全一致；4 可容忍重新编码与缩放。超过 8 时，分组只适合人工复核。

分组按浪费的空间从大到小排列。组内最大、分辨率最高的文件排在最前 —— 通常就是应该
保留的那个。

---

## 4. 取出路径

每个结果都带有完整路径：

- 底部的栏显示当前选中项的路径，**复制**会把所有选中的路径逐行复制；
- 文件名旁边的小复制图标只复制这一条；
- 右键菜单提供完整路径、相对于目录的路径，或在文件管理器中显示该文件。

---

## 5. 其他 git 分支

如果图片目录位于 git 仓库中，**分支…** 按钮就会可用。勾选需要的分支并点击
**建立索引**：它们的图片会直接从仓库中读取，因此不会检出任何内容，你的工作区
也不会被改动。你当前检出的分支不会出现在列表里 —— 它*就是*工作区。

分支列表就是索引内容的完整写照。取消勾选某个分支并重新建立索引，就会把它移除。

来自分支的结果会显示分支名，并以 `分支:路径` 的形式标识自己，而不是文件路径，
因为磁盘上并没有这样的文件。**打开**会把该版本提取到临时文件，方便你查看；在文件
管理器中显示、以及用它来搜索，都只适用于工作区中的文件。

重新建立索引的代价很低：分支顶端没有移动就整个跳过；在一个分支内部，也只有内容
确实变了的文件才会被重新读取。

> **Git LFS**：图片会从你本地的 LFS 存储中解析。如果某个分支从未拉取过，
> Argus 会告诉你缺少多少个对象，以及 `git lfs fetch --all` 可以取回它们 ——
> 它自己绝不会下载任何东西。

## 6. 主题与语言

**视图 → 主题**可在程序运行时切换系统、科幻、Material 和花语四种主题，选择会被
记住。

**视图 → 语言**同样无需重启即可切换界面。列表中包含此版本自带的所有语言；
**跟随系统语言**会随操作系统变化。本手册同样已翻译；对于手册尚未就绪的语言，会
回退为英文。

---

## 它做不到的事

- 感知哈希找的是**同一张图片**，绝不只是题材相近的图片。
- 神经网络搜索找的是图片中**确实存在**的素材，它不是按描述搜索。
- 若某个素材产生不了任何关键点 —— 纯色块、极小的图标 —— 就无法定位。典型素材库中
  大约 4% 属于这一类。
